Add a source

Paste a public careers page, ATS listing, job board, or GitHub internship list. Scout extracts HTML, JSON-LD, Markdown, and known ATS feeds without using an LLM.

Login-only pages, canvas-rendered listings, and sites that hide jobs behind custom interactions may return no roles. The source will still be saved so you can retry it later.
